# Documentation Website – Mintlify Clone

A **desktop-first documentation-style website clone inspired by Mintlify**, built using **pure HTML and CSS**.

This project focuses on replicating the **layout structure, sidebar documentation system, typography, spacing, and overall visual hierarchy** of the original Mintlify website with high accuracy, while strictly following the given constraints.

🔗 Original Website: https://mintlify.com/

## 🎯 Objective

- Recreate a documentation-style layout
- Match sidebar and main content alignment
- Maintain strong readability and structure
- Use semantic HTML and clean CSS
- Prioritize structural accuracy over creativity

- **CSS3** (Flexbox, Grid, spacing, typography)

## 🎨 Typography & Design System

- Clean documentation-style typography
